# Animated Skill/Progress Bars

A simple and responsive skill progress section built using HTML, CSS, and JavaScript.

The project displays different technical skills with animated progress bars that fill smoothly when the section becomes visible on the screen.

## Features

- Five skill progress bars with labels and percentages.
- Smooth filling animations.
- Gradient color effects.
- Scroll-based animation using IntersectionObserver.
- Responsive design for mobile and desktop.
- Configurable progress values using HTML data attributes.

## Technologies Used

- HTML5
- CSS3
- JavaScript


## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Scroll to the skills section to see the animations.

## Customization

To change a skill percentage, update the `data-width` attribute in the HTML file.

Example:

```html
<div class="progress-fill" data-width="90%"></div>
```
